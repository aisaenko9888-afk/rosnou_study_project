## 📋 Описание

Веб-приложение для демонстрации методологии внедрения ИИ-рекомендательных систем в интернет-магазины и сценарной оценки их экономической эффективности. Разработано в рамках магистерской диссертации на тему:  
**«Разработка рекомендаций по внедрению ИИ-технологий в создании интернет-магазинов для повышения пользовательского опыта и автоматизации бизнес-процессов»**.

### 🔍 Что делает система:
- **Item-Item Collaborative Filtering** — генерация товарных рекомендаций на основе косинусного сходства (Глава 1.1 ВКР)
- **Сценарный экономический анализ** — прогноз влияния ИИ на конверсию (+10–30%) и средний чек (+5–20%) (Глава 3.4 ВКР)
- **Расчёт ROI** — оценка окупаемости инвестиций с учётом затрат на внедрение (Формула 2.2 ВКР)
- **Визуализация результатов** — интерактивные графики и метрики эффективности

## 🧪 Пример использования

### Шаг 1: Подготовка данных
Подготовьте CSV-файл с историей покупок. Пример для магазина электроники:

```csv
user_id,item_id,rating
1001,SMARTPHONE_001,5
1001,HEADPHONES_007,4
1001,CASE_010,5
1002,SMARTPHONE_001,5
1002,CASE_010,4
1002,CHARGER_012,5
1003,LAPTOP_003,5
1003,MOUSE_008,4
1003,KEYBOARD_009,5
```

> 💡 **Требования:** минимум 100 записей, 10 уникальных пользователей, 5 товаров. Формат: UTF-8, разделитель запятая, обязательные столбцы: `user_id`, `item_id`, `rating`.

### Шаг 2: Запуск и загрузка
1. Запустите сервер:
   ```bash
   python app.py
   ```
2. Откройте в браузере: `http://127.0.0.1:5000`
3. В форме «Входные параметры»:
   - Нажмите «Выберите файл» и загрузите подготовленный CSV
   - Заполните бизнес-метрики (см. следующий шаг)

### Шаг 3: Настройка бизнес-параметров
| Параметр | Значение | Пояснение |
|----------|----------|-----------|
| Текущая конверсия | `2.5` | 2.5% посетителей совершают покупку |
| Средний чек | `8500` | Средняя сумма заказа в рублях |
| Месячный трафик | `25000` | Уникальные посетители в месяц |
| Стоимость ИИ | `750000` | Затраты на внедрение в год |

### Шаг 4: Запуск расчёта
Нажмите кнопку **«Рассчитать эффективность»**. Система выполнит:
1. Валидацию CSV и построение матрицы `User × Item`
2. Расчёт косинусного сходства между товарами
3. Генерацию топ-5 рекомендаций для первого товара в датасете
4. Прогноз выручки по двум сценариям (консервативный/оптимистичный)
5. Расчёт ROI по формуле из Главы 2.2 диссертации

## 🔎 Ожидаемые результаты

### 📊 Таблица рекомендаций
Система вернёт топ-5 товаров, наиболее схожих с целевым:

| № | ID товара | Коэффициент схожести |
|---|-----------|---------------------|
| 1 | `CASE_010` | `0.92` |
| 2 | `CHARGER_012` | `0.87` |
| 3 | `HEADPHONES_007` | `0.79` |
| 4 | `SMARTPHONE_002` | `0.65` |
| 5 | `SMARTWATCH_005` | `0.58` |

> 💡 **Как интерпретировать:** Коэффициент `0.92` означает высокую вероятность совместного спроса: пользователи, купившие `SMARTPHONE_001`, часто покупают и `CASE_010`. Товары с коэффициентом `>0.7` рекомендуются для блоков «С этим товаром покупают».

### 💰 Экономические метрики
| Показатель | Значение |
|------------|----------|
| Текущая выручка (мес) | `531 250 ₽` |
| Прогноз (мин) | `623 000 ₽` |
| Прогноз (макс) | `847 500 ₽` |
| ROI (мин) | `198%` |
| ROI (макс) | `556%` |

> 📈 **Как интерпретировать:** При внедрении ИИ ожидается рост месячной выручки на **17–60%** за счёт улучшения конверсии и кросс-продаж. Годовая окупаемость инвестиций: **198–556%** — проект экономически целесообразен.

### 📊 График эффективности
Система автоматически сгенерирует столбчатую диаграмму:
- 🔵 Синий столбец: текущая выручка
- 🟢 Зелёный: прогноз по консервативному сценарию
- 🟠 Оранжевый: прогноз по оптимистичному сценарию

### Шаг 5: Использование результатов
- **Для разработчиков:** интегрируйте список рекомендаций в блок «Рекомендуемые товары» на сайте.
- **Для маркетологов:** настройте email-рассылки с персонализированными предложениями на основе топ-5.
- **Для руководства:** используйте расчёт ROI для обоснования бюджета на ИИ-проекты.
